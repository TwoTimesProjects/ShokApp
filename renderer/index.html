Steam Integration
Steam API Key
Go to steamcommunity.com/dev/apikey, log in, and register a domain (anything works — even "localhost"). Your key is generated instantly.

Steam ID
Open Steam and go to your profile. The URL will show a long number like 76561198XXXXXXXXX — that's your Steam ID. If your URL uses a custom name instead, go to steamidfinder.com, enter your profile URL, and it'll give you the numeric ID.

How sync works
New entries are only created for Steam games currently installed on this machine. Uninstalled games are not added. For games already in the launcher, Steam playtime and last-played data is updated regardless of install status.
